# Rhythm Dance Studio

A dance studio website built with React, TypeScript and Vite. The goal was to create a website that feels like a dance studio brand, with a clean editorial look, bold typography and warm colours.

## About the project

Rhythm Dance Studio is a website concept for a dance community. It brings together information about classes, dancers, events and the studio in one place.

I focused on making the design feel welcoming and easy to explore, rather than using a standard website template.

## Features

- Home page with a large visual hero section
- Navigation for Home, Classes, Dancers, Events, About and Contact
- Dance photography and editorial-style typography
- Responsive layout for different screen sizes
- Custom 404 page
- GitHub Pages deployment using GitHub Actions

## Built with

- React
- TypeScript
- Vite
- CSS
- GitHub Pages
- GitHub Actions

## Run locally

Make sure Node.js is installed.

```bash
git clone https://github.com/darmigan2011-ops/dance-studio-website.git
cd dance-studio-website
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```
